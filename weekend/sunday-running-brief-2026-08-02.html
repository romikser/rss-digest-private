🗺 Route Picks for Sunday
TOP PICK Phoenix Park — Chesterfield Avenue loop
The classic Dublin long run. Chesterfield Avenue is 4.2km end-to-end; combine with the perimeter wall for 11km total. Deer likely out in the early morning mist. Flat and runnable in any weather — but a morning run here when it's quiet is genuinely special.
Distance: 8–11km · Surface: tarmac paths · From Liberties: ~20 min bike/bus · Google Maps · Apple Maps
Grand Canal — Portobello to Clondalkin towpath
Starts on your doorstep. Flat, sheltered towpath that stays runnable even if light drizzle arrives. Head west from Portobello for a quieter stretch; return via the same path or loop back on the road.
Distance: 6–10km · Surface: mixed (tarmac + gravel) · From Liberties: 5 min walk · Google Maps · Apple Maps
Howth Cliff Path SCENIC
Worth it if you leave early. Take the DART to Howth (35 min from Connolly), run the ~8km cliff loop, then head to the harbour for coffee. Check the weather window — if rain holds until afternoon you'll be back before it arrives.
Distance: ~8km loop · Surface: trail · DART from Connolly: 35 min · Google Maps · Apple Maps
👕 What to Wear
  • Short-sleeve top — 12–18°C range is comfortable for running; you'll warm up fast
  • Light windbreaker or packable jacket — easterly breeze will feel cool at the start; stuff it in your waistband once you're warm
  • Running shorts or 3/4 tights — either works; tights if you're going early morning when it's ~12°C
  • No rain jacket needed for a morning run — but bring one if you're heading out past 11am
  • UV Moderate — apply sunscreen if running between 9am–1pm, even through cloud cover
  • Grip shoes optional — Phoenix Park paths are tarmac and fine; Howth cliff path benefits from trail shoes if wet
